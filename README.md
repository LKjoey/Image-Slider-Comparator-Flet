### 使用方法

### 1. 安装 flet
```commandline
    pip install "flet[all]"
```

### 2. 运行
```commandline
    flet run main.py
```
或者 

直接在 pycharm 中运行 main.py 文件

### 其他

用鼠标控制滑动线，查看两张图片的对比效果
